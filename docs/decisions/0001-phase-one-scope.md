# ADR 0001：第一阶段采用本地优先 MVP

日期：2026-09-30  
状态：已接受

## 背景

LingoNest 的初始想法同时包含单词学习、AI、用户系统、游戏化、虚拟角色和商城。项目开发者需要在理解代码原理的同时逐步建立现代软件开发知识。如果第一阶段同时引入所有系统，范围和学习负担都会过大。

## 候选方案

### 方案 A：一次实现完整产品

同时加入登录、数据库、AI、角色、商城和复习。

优点：演示内容丰富。  
缺点：难以定位问题，学习负担大，容易产生无法解释的代码。

### 方案 B：先做本地优先 MVP

先实现单词、单词组、单词卡、复习、本地保存和基础统计，暂不接入 AI 和虚拟角色。

优点：可以快速验证核心学习闭环，数据流容易理解，范围可控。  
缺点：第一阶段看起来不够完整，暂时没有跨设备同步。

## 决定

采用方案 B。

第一阶段必须支持：

- 添加单词。
- 用英语或中文填写解释。
- 创建和使用用户自己的单词组。
- 查看单词卡。
- 进行简单复习。
- 保存单词和复习记录。

第一阶段不接入 AI、虚拟角色、商城、抽奖和云端用户系统。

## 后果

- 第一阶段可以更早获得可运行结果。
- 后续接入后端和 AI 时，需要考虑如何迁移本地数据。
- 游戏化设计暂时只能保留极简积分反馈。
- 产品是否长期有价值，先由“用户是否愿意记录和复习单词”来验证。
