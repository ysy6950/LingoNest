# ADR 0007：设备朗读、词典音标与美式音频

- 状态：已采纳；用户于 2026-10-26 确认 4.2 完成；正式发布授权范围仍须复核
- 日期：2026-10-24

## 背景

用户需要听到单词读音并看到音标。音标不能要求学习者手动填写，也不能把 AI 猜测的音标当作词典事实。现有单词、复习状态和 AI 学习笔记必须在升级后保留。

## 决策

1. 美式发音使用 Merriam-Webster's Learner's Dictionary with Audio 返回的公开音频文件；英式发音使用 Expo Speech 调用 Android 设备的 `en-GB` 语音能力。设备语音包的声音、网络依赖与可用性因设备而异。
2. 音标、词性和美式音频信息由电脑后端查询 Merriam-Webster's Learner's Dictionary with Audio。Key 只放在 `server/.env`；手机通过已有局域网配对接口发送单词，不直接访问词典 API。后端只返回 IPA、词性、固定媒体域名下的美式音频地址、来源和查询时间，错误不返回密钥或原始供应商正文。
3. 查询结果先预览，用户确认才附加到单词卡。原解释、AI 笔记和复习进度不变；修改单词拼写后清除旧音标，修改解释则保留。
4. 本地快照由 `lingonest.v2` 迁移为 `lingonest.v3`，新增可选的 `pronunciation` 字段。迁移成功写入 v3 后才开放界面；旧 v2 键保留作恢复副本。迁移失败不覆盖旧键或播种示例词。电脑已有 v2 备份仍可读取并在手机恢复为 v3；v3 备份不保证旧版 App 可读。
5. 词典结果界面显示官方标志和完整产品名称；正式发布前还需复核供应商许可、使用量和品牌要求。
6. 2026-10-26 修正音频地址：按词典文档的 `en/us/mp3/{subdirectory}/{audio}.mp3` 规则拼接，已有 v3 卡片的旧平铺地址在读取时改为规范地址，无需改快照版本。播放器等待加载并显示超时/失败状态，避免无声无反馈。

## 取舍与复核

词典美式音频比通用 TTS 更接近词典示范发音，但需要电脑后端联网查询，手机播放时也需要访问公开媒体地址；没有音频时仍保留英式设备朗读。音标使用词典查询比 AI 猜测可靠，但需要有效的指定词典 Key。若以后需要离线音频、英式真人录音或更广泛的词形覆盖，应单独比较许可与本地缓存；本轮不代理、下载或永久保存音频文件。
