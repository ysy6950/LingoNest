# ADR 0016：局域网账号与按用户备份

日期：2026-11-03。状态：5.1b 后端实现；手机接入待 5.1c。

## 决定

在已有 Express + SQLite 中新增账号、邀请码、会话和每人一份备份。账号模式必须同时配置局域网 IP、备份接口和 HTTPS，并通过 `LINGONEST_ACCOUNTS=1` 显式开启。旧配对码模式暂留供当前 APK 使用；账号模式中，旧配对码不能访问任何受保护接口。无新云服务、邮件或第三方认证依赖。

电脑主人在本机创建首位管理员邀请；后续成员可由管理员或本机命令邀请。密码使用随机盐与 Node `scrypt` 校验，不保存原文。会话和一次性凭据使用强随机值，SQLite 仅存 SHA-256 摘要；会话有效 30 天，退出或改密后可撤销。忘记密码经本机/管理员生成一次性重置凭据；无邮件找回。

备份接口从会话决定 `userId`，按人保存 `revision`；仍要求调用方确认 `serverId`、符合现有快照协议与大小上限。旧 `backup(id=1)` 继续留在原表且不对账号开放。本机认领命令需要明确管理员用户名、当前数据库 `serverId`、旧 revision、目标账号尚无备份，执行复制并保留原件。手机游客词库迁入与会话安全存储由 5.1c 处理。

AI 分析、推荐和练习使用账号范围作为内存缓存及请求合并键；使用统计按人查询，全局并发限制仍为两个任务。管理员可清理全局缓存；普通成员不得清理或列出用户。词典查询仅需有效会话。

## 取舍与边界

自己维护局域网账号比使用云登录更适合当前无公网、无 SMTP 的试用目标，但电脑关闭时仍无法登录或备份。密码及会话只保护 API，电脑磁盘中的 SQLite 快照未额外加密；设备主人应保护电脑与数据库文件。邀请、会话和重置令牌不会在管理日志中重复输出，第一次显示后应私下保存或传递。当前未做自动同步、账号删除、跨局域网访问。客户端 0.5.2 不认识账号会话，不能直接启用账号模式替代现有配对码。

密码参数参照 [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
