# ADR 0017：手机账号词库隔离与游客资料复制

日期：2026-11-03。状态：5.1c 源码实现，Android 真机多人回归待验证。

## 决定

账号登录从局域网 HTTPS 后端取得 `serverId`、`userId` 和有期限的会话令牌。令牌放在 Android SecureStore，不放在 AsyncStorage、单词快照或 Git。电脑连接地址和已验证的当前账号资料保存在安全会话中；手机重新打开时可离线继续查看该账号的本地词库，但首次登录、备份和 AI/词典请求需要连接电脑。网页开发预览的会话仅保留在内存，不作为正式登录存储。

游客继续使用原 `lingonest.v3`、恢复副本和补全待办键，不自动迁移。账号词库、恢复副本和补全待办按 `serverId + userId` 分别存储。切换前等待本地写入；未保存成功时拒绝切换。切换时先遮住学习页面、断开旧电脑身份，再读取目标本地资料，最后启用新身份；页面与自动补全执行器按账号重建。退出前确认游客词库能读取，避免清除凭据后仍显示原账号资料。修改密码后后端已撤销旧会话，手机仅清理本地会话，不再使用旧令牌请求退出。请求回包若发现连接发生过切换，即使又切回原账号，也不能更新页面。备份恢复在数据写入处再校验发起时的账号范围。

游客词库只在本人于账号页确认、当前账号本机词库为空、电脑目标账号尚无备份时复制。复制保留游客原件，不自动上传或合并；之后由用户手动备份。电脑旧单份备份只能由电脑主人按 ADR 0016 的本机命令认领，手机不会自动拿走。

## 取舍

先沿用 AsyncStorage 保存每人完整 v3 快照，避免在当前阶段迁移到新数据库；手机资料不是应用层加密存储，设备本身应妥善保护。会话令牌使用 SecureStore，是为了避免把登录凭据和普通学习数据混存。退出会向电脑撤销会话，必须连上电脑；网络断开时继续离线学习，稍后再退出。若会话过期，可保留本机资料并重新登录，不能用旧会话访问电脑。自动同步和跨网络使用仍不在本阶段。
