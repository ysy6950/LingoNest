## 2026-10-01：Git 基础

### 我的理解

- 工作区：当前正在查看和修改的实际项目文件。
- Git 仓库：保存项目提交历史和 Git 管理信息的地方。
- Commit：一次被正式记录的项目快照，包含文件变化、作者、时间和说明。
- main：当前项目主要开发路线的分支名称。
- .gitignore：告诉 Git 忽略哪些尚未被跟踪的本地文件。

### 实际练习

- 查看了项目状态。
- 查看了提交历史。
- 查看了最近一次提交的文件统计。
- 修改了全局 Git 邮箱。
- 创建了第一个练习分支。

### 仍需学习

- 暂存区是什么。
- 如何提交分支中的修改。
- 如何把分支合并回 main。
- 如何在 GitHub 上发起 Pull Request。
