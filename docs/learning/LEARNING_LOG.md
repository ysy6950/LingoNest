## 2026-10-01：Git 基础

### 我的理解

- 工作区：当前正在查看和修改的实际项目文件。
- Git 仓库：保存项目提交历史和 Git 管理信息的地方。
- Commit：一次被正式记录的项目快照，包含文件变化、作者、时间和说明。
- main：当前项目主要开发路线的分支名称。
- .gitignore：告诉 Git 忽略哪些尚未被跟踪的本地文件。

### 实际练习

- 查看了项目状态。
- 查看了提交历史。
- 查看了最近一次提交的文件统计。
- 修改了全局 Git 邮箱。
- 创建了第一个练习分支。

### 已完成的后续练习

- 理解并使用暂存区。
- 在练习分支创建提交。
- 把练习分支合并回 `main`。
- 删除已合并的临时分支。

### 以后按需学习

- 如何连接 GitHub 和推送远程分支。
- 如何发起 Pull Request 并配合代码审核。
- 如何解决合并冲突。
- 如何安全撤销已经提交的错误。

常用命令见 [GIT_CHEATSHEET.md](GIT_CHEATSHEET.md)。

## 2026-10-03：多个单词卡

### 学到的概念

- 数组状态：用一个数组保存多张单词卡。
- `map`：遍历数组，并生成新的单词卡数组或多个界面元素。
- 对象身份：用 `id` 找到用户点击的那张卡，避免修改其他卡片。
- 不可变更新：保留旧数组内容，创建包含修改结果的新数组。

### 实际结果

- 可以连续添加多个单词。
- 页面同时显示所有已添加的单词卡。
- 每张卡可以独立显示或隐藏自己的解释。
- 手机 Expo Go 测试通过。

### 下一步

- 学习本地持久化，让单词在应用重启后仍然存在。

## 2026-10-03：本地持久化

### 学到的概念

- 依赖：项目需要使用的外部软件包；`@react-native-async-storage/async-storage` 是当前移动端项目的依赖。
- `AsyncStorage`：通过键和值保存少量本地数据的异步存储库。
- `useEffect`：在组件加载或依赖数据变化时执行读取、保存等副作用。
- JSON：把 JavaScript 数组转换成文字保存，再转换回数组。

### 实际结果

- 应用启动时从手机本地读取单词卡。
- 添加单词后自动保存新的单词数组。
- 关闭并重新打开 Expo Go 后，单词仍然存在。
- 使用 Expo SDK 57 兼容的 AsyncStorage `2.2.0`。

### 下一步

- 增加最简单的复习操作，记录用户是否认识单词。

## 2026-10-03：基础复习

### 学到的概念

- 联合类型：`'known' | 'unknown'`，把结果限制为有限的几个合法值。
- 可选属性：`reviewResult?` 和 `lastReviewedAt?` 允许新单词在尚未复习时没有结果。
- 复用事件处理函数：`handleReview(cardId, result)` 同时处理“认识”和“不认识”。
- 数据流：用户操作更新 `cards`，统一的 `useEffect` 再负责持久化。

### 实际结果

- 每张单词卡可以选择“认识”或“不认识”。
- 保存最近一次复习结果和复习时间。
- 复习后自动显示解释，并在重启后保留结果。
- 手机 Expo Go 测试通过。

### 遇到的困惑与解决

- 困惑：为什么复习函数还要传 `cardId`，还要遍历数组？
- 解决：多张卡拥有各自状态，程序必须先通过 id 找到目标卡，再只更新目标卡，其他卡片保持不变。

### 下一步

- 从现有 `cards` 计算最基本的学习统计。

## 2026-10-05：基础学习统计

### 学到的概念

- `filter`：从数组中筛选符合条件的元素。
- `length`：取得数组元素数量。
- 派生数据：可以从已有 `cards` 计算出来的统计数字，不单独保存一份。

### 实际结果

- 显示单词总数。
- 显示已复习、认识和不认识的数量。
- 统计会随着复习结果自动更新，并在重启后根据已保存的 `cards` 重新计算。
- 手机 Expo Go 测试通过。

### 遇到的困惑与解决

- 困惑：为什么不为每个统计数字建立单独的状态？
- 解决：统计数字可以由 `cards` 计算，`cards` 作为唯一真实数据来源可以避免两套数据不一致。

### 下一步

- 整理 MVP 验收场景和人工测试记录。

## 2026-10-03：输入并添加单词

### 学到的概念

- `TextInput`：React Native 提供的移动端输入框。
- 受控输入：输入框的内容由 React 状态保存，并通过 `value` 和 `onChangeText` 同步。

### 实际结果

- 可以输入单词和英语或中文解释。
- 点击“添加单词”后，当前单词卡会显示新内容。
- 空单词或空解释不会被添加。
- 手机 Expo Go 测试通过。
