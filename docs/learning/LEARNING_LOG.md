# LingoNest 学习记录

## 规则

- 不把“看过教程”当成“已经掌握”。
- 每个概念尽量配一个小练习。
- 练习优先与 LingoNest 的真实需求相关。
- 如果一个概念暂时不影响当前阶段，就记录后暂缓深入。
