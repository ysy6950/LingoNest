## 2026-10-01：Git 基础

### 我的理解

- 工作区：当前正在查看和修改的实际项目文件。
- Git 仓库：保存项目提交历史和 Git 管理信息的地方。
- Commit：一次被正式记录的项目快照，包含文件变化、作者、时间和说明。
- main：当前项目主要开发路线的分支名称。
- .gitignore：告诉 Git 忽略哪些尚未被跟踪的本地文件。

### 实际练习

- 查看了项目状态。
- 查看了提交历史。
- 查看了最近一次提交的文件统计。
- 修改了全局 Git 邮箱。
- 创建了第一个练习分支。

### 已完成的后续练习

- 理解并使用暂存区。
- 在练习分支创建提交。
- 把练习分支合并回 `main`。
- 删除已合并的临时分支。

### 以后按需学习

- 如何连接 GitHub 和推送远程分支。
- 如何发起 Pull Request 并配合代码审核。
- 如何解决合并冲突。
- 如何安全撤销已经提交的错误。

常用命令见 [GIT_CHEATSHEET.md](GIT_CHEATSHEET.md)。

## 2026-10-03：第一个移动端界面

### 学到的概念

- React 状态：组件内部用来记住会变化的数据；本次用 `showMeaning` 记录解释是否显示。
- React Native 组件：用 `View`、`Text` 和 `Pressable` 组合出移动端界面。
- Expo：负责启动 Metro 开发服务器，让应用代码可以被预览和调试。

### 实际结果

- 在 `mobile/` 初始化 Expo + TypeScript 项目。
- 完成 `persist` 单词卡，可以点击按钮显示或隐藏英语解释。
- `npx tsc --noEmit` 检查通过。

### 下一步

## 2026-10-03：输入并添加单词

### 学到的概念

- `TextInput`：React Native 提供的移动端输入框。
- 受控输入：输入框的内容由 React 状态保存，并通过 `value` 和 `onChangeText` 同步。
- 事件处理函数：点击“添加单词”时，`handleAddWord` 检查输入并更新卡片。

### 实际结果

- 可以输入单词和英语或中文解释。
- 点击“添加单词”后，当前单词卡会显示新内容。
- 空单词或空解释不会被添加。
- 手机 Expo Go 测试通过。

### 下一步

- 学习数组状态，让应用同时保存并显示多个单词。
