# LingoNest 产品模块地图

## 阶段标签

- P1：本地 MVP 阶段。
- P2：云端和 AI 阶段。
- P3：游戏化阶段。
- Later：很后面再考虑。

| 模块 | 解决的问题 | 用户使用方式 | 计划阶段 | 后续方向 |
|---|---|---|---|---|
| 用户系统 | 区分用户并保护个人数据 | 注册、登录、退出 | P2 | 多设备同步、账号恢复 |
| 单词系统 | 快速记录遇到的单词 | 输入单词、解释和备注 | P1 | 标签、搜索、导入 |
| 单词组 | 按主题或个人目标组织单词 | 创建单词组并加入单词 | P1 | 学习计划、共享词组 |
| 单词卡 | 以低负担方式查看和记忆 | 正面看单词，翻面看解释 | P1 | 音频、图片、词性 |
| 复习系统 | 解决“保存后不再复习” | 选择认识或不认识 | P1 | 间隔复习、难度调整 |
| 练习系统 | 检查是否真正理解 | 选择题、填空、判断题 | P2 | 多题型、自适应难度 |
| AI 单词分析 | 降低整理和理解成本 | 请求释义、词性和重点 | P2 | 上下文解释和个性化 |
| AI 推荐 | 发现值得一起学习的词 | 查看近义词、反义词、搭配 | P2 | 主题词网和个性推荐 |
| AI 例句 | 理解真实语境 | 查看英文例句和解释 | P2 | 根据水平和兴趣生成 |
| 游戏化 | 提供学习反馈和动力 | 完成学习获得积分 | P1 极简/P3 完整 | 任务、成就、成长 |
| 虚拟角色 | 提供情感反馈 | 查看角色和成长状态 | P3 | 对话、性格、故事 |
| 商城 | 让长期积分有使用方向 | 购买装饰物品 | P3 | 家具、服装、房间主题 |
| 道具 | 将奖励转化为可使用内容 | 获得、使用或摆放物品 | P3 | 食物、礼物、装扮 |
| 学习统计 | 帮用户看到自己的进步 | 查看学习量和复习情况 | P1 | 准确率、趋势、薄弱词 |

## 产品依赖

```text
单词系统
  → 单词组和单词卡
  → 复习系统
  → 学习统计
  → AI 内容
  → 游戏化反馈
```

如果单词记录和复习闭环不稳定，后面的 AI 和游戏化都没有可靠基础。
