# LingoNest 第一阶段 MVP

## 产品假设

英语基础较弱的用户愿意使用一个简单工具，快速记录自己遇到的单词，用英语或中文理解它们，建立自己的单词组，并通过及时复习巩固记忆。

## 第一阶段目标

验证以下核心闭环：

```text
添加单词
→ 填写英语或中文解释
→ 加入自己的单词组
→ 查看单词卡
→ 进行一次复习
→ 保存复习记录
→ 重新打开后继续使用
```

## MVP 必须有

1. 添加单词。
2. 为单词填写英语解释、中文解释或两者之一。
3. 创建、查看和选择用户自己的单词组。
4. 将单词加入或移出单词组。
5. 查看已有单词。
6. 单词卡正面显示单词，背面显示解释。
7. 复习时选择“认识”或“不认识”。
8. 保存最近一次复习结果和时间。
9. 关闭并重新打开后，单词和复习记录仍然存在。
10. 显示最基本的学习统计，例如单词总数和今日复习数。

## MVP 可以没有

- AI 分析、AI 推荐、AI 例句和 AI 练习题。
- 登录、云端同步和多设备数据。
- 虚拟角色、房间、家具和商城。
- 抽奖、复杂金币经济和付费系统。
- 推送、社交、排行榜和成就系统。
- 复杂的高级间隔复习算法。

## 第一阶段的学习反馈

如果需要验证奖励闭环，只增加一个简单学习积分计数，不建立可购买商品，也不设计随机奖励。积分的目的只是确认“学习行为可以产生反馈”，而不是在第一阶段完成完整游戏系统。

## 验收标准

一个新用户不看开发者说明，可以在 3 分钟内：

1. 打开应用。
2. 添加第一个单词。
3. 填写至少一种解释。
4. 查看单词卡正反面。
5. 完成一次复习。
6. 关闭并重新打开应用。
7. 看到之前的单词和复习记录仍然存在。

开发者本人还必须能够用自己的话解释这个流程涉及的界面、状态和数据保存原理，并能和别人进行基本技术交流。

## 明确的非目标

第一阶段不是为了证明我们能同时使用 AI、后端、数据库和游戏引擎，而是为了证明一个小而完整的学习产品闭环可以被理解、运行和验证。
