## 2. 当前能力与限制

- 手机本地添加、分组、编辑、浏览、复习和统计不依赖电脑后端；数据使用 AsyncStorage v3 保存，兼容旧格式。
- AI 笔记支持解释、三个例句、预览确认和保存后编辑；关联词逐项确认加入。自动补全默认关闭，用户开启后生效。
- 语境练习支持手动或随机选词，手机生成选项并判分；练习结果暂不保存、不改变复习记录。
- 音标、词性及美式音频来自词典；英式朗读使用设备语音。首次查询和网络音频需要联网。
- Express 后端通过配对提供 AI、词典及备份服务；SQLite 只保存最新完整备份，没有独立词汇关系表。
- API Key 留在电脑端；手机连接电脑仍限可信局域网。当前没有账号、多用户隔离、自动云同步或公开部署。

完整机制见[架构说明](../architecture/ARCHITECTURE.md)、[数据迁移](../architecture/DATA_MIGRATIONS.md)和[词典来源](../reference/DICTIONARY_DATA.md)。
