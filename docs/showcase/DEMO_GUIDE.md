# LingoNest 求职展示演示稿

本演示突出一个可运行的小产品、清晰的边界和真实的工程记录，不把未完成的账号、云同步或游戏化描述成已有能力。

## 1. 演示前准备

1. 在电脑 `server/` 以局域网备份模式启动后端，确认配置状态；终端会显示临时配对码，录屏时隐藏该区域，不展示 Key 或 `.env`。
2. Android 与电脑连接可信 Wi-Fi，打开 LingoNest 后连接并配对。
3. 预先准备 4～5 个公开测试词，例如 `learn`、`apple`、`bicycle`、`honest`、`quickly`；不要使用个人信息。
4. 关闭不需要的自动补全，避免演示期间产生额外请求；需要展示时再主动开启。
5. 记录演示日期、设备、服务商和模型；不记录配对码或密钥。

## 2. 建议流程

下表是约 6 分钟的讲解安排，不是实测完成时间；AI 网络等待另计，可提前准备一次生成结果。

| 时间 | 操作 | 要展示的能力 |
|---|---|---|
| 0:00 | 添加单词并选择分组 | Android 表单、分组和本地保存 |
| 0:45 | 打开详情、翻面、播放音频 | 卡片交互、IPA/词性、美式音频或设备朗读 |
| 1:30 | AI 辅助生成预览，修改后确认保存 | 手机只请求本地后端、预览确认、不覆盖原解释 |
| 2:30 | 关联词推荐，逐项修改并加入 | 词典只核对词形、用户控制导入 |
| 3:30 | 选择或随机选择 4～5 个词生成语境练习 | AI 生成草稿，手机生成选项并判分 |
| 4:30 | 设置页查询用量和缓存状态 | 有界缓存、并发控制、安全聚合统计 |
| 5:00 | 停止电脑后端，继续查看和复习 | AI 不可用时本地学习仍可用 |

## 3. AI 不可用演示

在完成一次正常保存后，只停止运行 `server/` Express 后端的终端，保留运行 `mobile/` Expo Metro 开发服务的终端及手机网络连接。回到手机：

- 已保存单词、解释、音标和 AI 笔记仍可查看。
- 可以添加、编辑、翻面和完成本地复习。
- 再次点击 AI 或词典功能时显示可理解的失败提示，不覆盖旧内容。
- 恢复电脑和网络后重新配对，备份和 AI 功能恢复。

这段演示验证“AI 后端不可用仍能本地学习”。首次 AI 生成和词典查询需要联网，美式网络音频不能保证离线播放。Expo Go 可能需要 Metro 加载开发项目；独立安装包离线冷启动尚未验收。

用户于 2026-10-29 补充了复习完成截图，并说明拍摄时 Express 后端已停止。单张复习截图只能展示本地学习结果，无法独立证明服务器状态；若需要展示完整过程，可录一段包含停止 Express、手机完成复习、重开后记录仍在的短视频。独立安装包离线冷启动仍未验收。

## 4. 截图要求

至少准备以下真实 Android 截图：

1. 单词组双列卡片和搜索；
2. 详情页的单词、音标、词性和发音入口；
3. 已保存 AI 学习笔记；
4. 关联词推荐及词形家族说明；
5. 语境练习结果（完成页与结果列表较长时使用两张连续截图）；
6. AI 用量页；
7. 后端停止期间完成的本地复习。
