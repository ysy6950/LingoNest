# 4.2 发音、音标和数据升级验收

状态：用户于 2026-10-26 开始 4.3 前确认 4.2 已完成；包含此前的音频 URL、跨页配对与单词附近「🔊 美」「🔊 英」入口调整。以下清单保留用于回归；用户未提供逐项数据，实测栏不虚构填写。不要清除 App 数据。不要把 API Key 或配对码贴进聊天、截图或仓库。

## 准备

1. 确认 `server/.env` 只有电脑保存的 `LINGONEST_WEBSTER_KEY`。默认词典 URL 已写在后端，通常**不需要**另配 URL。Key 必须属于 Merriam-Webster's Learner's Dictionary with Audio，而不是其他词典。
2. 在 `server/` 停止旧进程，按 `server/README.md` 的 3.0d 配对局域网方式重新运行 `npm.cmd start`。启动行的 `Dictionary configuration: configured` 只说明有 Key，并不证明供应商接受该 Key。
3. 在 `mobile/` 运行 `npx.cmd expo start -c`，用支持 SDK 58 的 Android Expo Go 重载 App，保持电脑与手机在同一可信 Wi-Fi。不要卸载 Expo Go 或清除应用数据。
