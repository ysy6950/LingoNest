状态：2026-10-27 用户反馈除推荐超时外其他测试无问题；已实现超时修复并通过自动检查，待 Android 和真实服务商回归。用户未提供的逐项结果不补填。

## 快速操作

不清除手机数据，不更改已经工作的 `.env`，不需要安装新依赖。

1. 在原后端窗口按 Ctrl+C，保持原局域网启动环境，在 `D:\Project\LingoNest\server` 执行 `npm.cmd start`。服务重启会生成新配对码。
2. 手机上重载 Expo Go，在设置/电脑连接页用新码重新配对。只有手机重载不够，电脑必须运行更新后的提示词与校验代码。
3. 打开一个已有常见单词的详情，进入“关联词推荐”，生成或重新生成。可用 `care`、`learn` 等已收录词分开试几次；不要求每次都有四类推荐，AI 可以省略不合适的类别。
4. 在“同词根 / 词形家族”的候选中检查分类、词根/基础词/原形、中文含义、适用词缀和推荐理由；理由应能解释原词与候选的联系。不要仅凭两词拼写相似就认可关系。
5. 明确看到“AI 构词分析，词源尚未经核实；词典仅核对词形。”不确定时显示待确认，不虚构来源。使用可信词典或词源参考人工抽查多个真实结果；如发现不准确，记录原词、当前解释、候选和错误点，不记录密钥。
6. 取消加入不增加单词；确认一项后仍可选择分组、修改解释，保存为普通单词卡。新卡待复习、原词复习次数不变；已开启 4.3.1 自动补全时，新词继续按开关补全，预览不会自动收录整批词。
