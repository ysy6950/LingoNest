## 准备与快速验收

不清除 App 数据；沿用 `server/.env` 里的 AI 配置和 `LINGONEST_WEBSTER_KEY`，不需要新增配置，不分享 Key 或配对码。

1. 在原后端 PowerShell 窗口按 `Ctrl+C`，在 `D:\Project\LingoNest\server` 运行 `npm.cmd start`。同一窗口保留原局域网变量；启动应显示 LAN backup server、AI configured 与 Dictionary configured。`start` 不自动加载代码修改，必须重启。若使用新窗口，按 `server/README.md` 的 3.0d 步骤重新设置局域网 IP、端口与备份模式。
2. 手机重新加载 Expo Go。电脑重启后配对码已更新，首次请求输入本次新码；成功后 AI、词典和备份复用本次 App 会话的连接。
3. 打开有明确解释的常见词，如 `serene`（平静、宁静），进入单词卡下方“拓展这个单词 → 关联词推荐”，点击“生成关联词”。
4. 检查候选解释、理由、类别及核对状态。选一项，修改解释、选择分组、确认加入。到目标组查看新卡、复习页查看新增待复习词；原词解释和复习状态应不变。
5. 完全关闭重开 App，确认新词和分组保留。推荐列表本身不保存，这是预期行为。
