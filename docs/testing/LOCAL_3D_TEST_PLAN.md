## 自动化覆盖

- `server/tests/pairedBackup.test.ts`：配对失败、旧数据库标识、缺失复习数据及版本冲突拒绝。
- `server/tests/backup.test.ts`：SQLite 重启持久化、坏数据与大小限制。
- `mobile/tests/localBackup.test.mjs`：真实 Express + SQLite 与手机请求模块互通（电脑上执行）；响应丢失、格式拒绝、确认期间本机/电脑变化及手机写入失败。
- `mobile/tests/store.test.mjs`：恢复留档、撤销、重启保存；恢复三次写入中任一步失败，当前数据不被覆盖。

先在 `mobile/` 和 `server/` 都执行 `npm.cmd install`，再分别运行 `npm.cmd run typecheck`、`npm.cmd test`。手机测试中的真实 HTTP 互通用例需要已安装的服务端依赖。自动结果不能替代以上 Android 实测。
