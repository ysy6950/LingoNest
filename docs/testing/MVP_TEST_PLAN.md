# LingoNest MVP 测试计划

## 文档目的

本文件记录第一阶段 MVP 的人工测试场景、预期结果和实际结果。它不是测试代码，而是验证产品行为是否符合需求的检查表。

## 测试环境

- 设备：Android 手机
- 运行方式：Expo Go
- 应用目录：`mobile/`
- 数据存储：AsyncStorage 本地存储
- 测试日期：2026-10-05

## 验收标准

新用户不查看开发者说明，可以在 3 分钟内完成：

1. 添加第一个单词。
2. 填写解释。
3. 查看单词卡正面和解释。
4. 完成一次“认识”或“不认识”复习。
5. 重新打开应用后看到单词、复习结果和统计仍然存在。
