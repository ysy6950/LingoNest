## 明早快速验收顺序

先不要清除 App 数据，保留已有数据以验证迁移。启动开发服务器后，在 Expo Go 重新加载应用，依次检查：

1. **添加**：默认进入添加页；输入一个新词和解释，选择分组后保存；看到成功提示且输入框清空。
2. **四个入口**：点击底部“添加、单词组、复习、统计”，每页都能打开，底部导航仍可用。
3. **单词组**：进入某个组，看到两列卡片；搜索刚添加的词；切换“最近添加 / 字母顺序 / 待复习优先”。
4. **卡片详情**：点卡片进入详情，点卡片翻面，观察过渡是否自然；返回后确认浏览没有把卡片标为已复习。
5. **管理**：修改解释并保存；移动到另一个组后从原组消失、在新组出现；删除前有确认，删除后卡片不再出现。
6. **复习**：进入复习页，开始一张卡；未翻面前不应显示反馈按钮；翻面后选择“记住了”，确认进入下一张或显示总结。
7. **间隔**：选择结果后回到复习页，卡片不再立即出现在到期队列；查看卡片详情可以看到下一次复习安排。测试时不必等待十分钟，可记录显示的到期时间。
8. **统计**：检查收录数、待复习数、今日复习数和累计反馈次数随操作变化。
9. **重启**：关闭并重新打开 Expo Go，确认新词、分组、编辑结果、复习结果和下次到期时间仍在。
10. **计时**：清楚测试步骤后，从打开添加页开始计时，到完成一次复习结束；记录是否在 3 分钟内。
