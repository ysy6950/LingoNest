# LingoNest MVP 测试计划

## 文档目的

本文件记录第一阶段 MVP 的人工测试场景、预期结果和实际结果。它不是测试代码，而是验证产品行为是否符合需求的检查表。

## 测试环境

- 设备：Android 手机
- 运行方式：Expo Go
- 应用目录：`mobile/`
- 数据存储：AsyncStorage 本地存储
- 测试日期：2026-10-05

## 验收标准

新用户不查看开发者说明，可以在 3 分钟内完成：

1. 添加第一个单词。
2. 填写解释。
3. 查看单词卡正面和解释。
4. 完成一次“认识”或“不认识”复习。
5. 重新打开应用后看到单词、复习结果和统计仍然存在。

## 尚未完成的 MVP 项目

- 用户创建单词组。
- 将单词加入或移出单词组。
- 更细的“今日复习数”统计。

这些项目属于当前 MVP 范围，不能在发布“完整第一阶段 MVP”时声称已经完成。

## 当前明确不测试

- AI 分析和推荐。
- 登录和云端同步。
- 虚拟角色、商城和抽奖。
- 高级间隔复习算法。

## 测试记录规则

每次测试至少记录：

- 测试日期和设备。
- 使用的测试数据。
- 操作步骤。
- 预期结果和实际结果。
- 通过、失败或阻塞。
- 如果失败，关联 `docs/learning/TROUBLESHOOTING_LOG.md`。
