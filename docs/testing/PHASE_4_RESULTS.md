## 3. 性能与错误边界

- AI 服务商等待上限为 90 秒，手机等待上限为 120 秒；超时不代表服务商撤销了请求，也不自动重试。
- 词典后端请求上限为 10 秒，手机请求上限为 15 秒；词典超时只影响本次资料获取，不清除原单词。
- AI 成功结果只在电脑内存缓存 24 小时，最多 200 条；练习完成结果不缓存。电脑重启后缓存和统计归零。
- 聚合用量不是供应商账单，不包含词典请求、令牌、金额或硬性费用上限。
- 电脑服务停止、断网或 AI/词典未配置时，本地添加、编辑、查看和复习仍可用。
- 上述秒数、容量和并发数都是程序限制，不是实测响应性能；当前没有记录平均/P95 延迟、帧率、耗电或大词库压力测试，不能声称这些指标达标。

## 4. 数据安全边界

- 设计要求 API Key 只在电脑后端环境变量中，`.env` 被 Git 忽略；接口不向手机返回 Key。该记录不代表已经完成全部 Git 历史或所有文件的密钥审计。
- 手机 AsyncStorage 和电脑 SQLite 没有应用层加密；当前不提供账号隔离或公开服务的用户认证。
- 手机到电脑的局域网 HTTP 未加密，只使用可信私人网络，不公开端口。
- 配对码仅本次后端运行有效，错误或过期后拒绝备份、AI 和词典请求。
- AI 请求会发送用户输入的单词和解释到已配置的外部服务商；演示时使用公开测试词，不发送个人信息。
- 日志只保留错误类别、必要状态和耗时，不记录 Key、完整请求体或服务商原始响应。
