## 真机准备

1. **先保护现有数据**：在当前已安装版核对游客或账号词库、分组和复习进度，用对应身份手动备份并核对时间；升级安装时不要卸载 App 或清除数据。备份电脑数据库文件到个人安全位置，不上传 GitHub。
2. 从 [0.5.6 APK](https://expo.dev/artifacts/eas/55Il-KtXzo_bxaG5_LzHg0AMomgb0unPVGAO3JH2uUk.apk) 升级安装，确认原词库仍可打开。链接有效至 2026-11-19；此包内置与 5.1a 相同的公开 CA。Expo Go 不能代替此自定义 CA 安装包验证 HTTPS。
3. 停止旧后端。电脑在 `server/` PowerShell 设置正确的 `LINGONEST_LAN_IP`、`LINGONEST_LAN_BACKUP=1`、`LINGONEST_LAN_TLS=1`、`LINGONEST_ACCOUNTS=1`，再运行 `npm.cmd start`。`/health` 应显示 `lan-accounts`。账号模式开启后，旧 APK 的配对码电脑功能会返回 401；手机离线词库不受影响。
4. 首次创建管理员时，电脑主人在 `server/` 运行 `npm.cmd run accounts -- invite-admin`，私下保管这串一次性邀请码；已有管理员直接在底部「我的」登录，不需重新生成管理员邀请码。新成员由管理员在账号页生成邀请码。填写电脑地址、邀请码、用户名、昵称和密码。邀请码、密码、会话令牌不要截图或发到聊天。

## 两个账号的验证

- 管理员从「我的」→「邀请新成员」生成一个成员邀请码；第二个人在另一台手机安装同一 APK 并注册。两人各添加一个不同的单词、复习一次，关掉 App 再打开，确认本地资料保留。
- 在第一台手机登录 A，添加专属单词；切换到 B 应看不到 A 的单词；切回 A 后仍在。切回游客应看到升级前的游客词库和复习记录。断开电脑时，已验证的当前账号仍能离线添加与复习，第一次登录不能离线完成。
- 各自读取电脑备份，先确认目标账号显示为空，再手动备份；A 读取不到 B 的内容，B 的操作不覆盖 A。用错误密码、过期/撤销会话访问应被拒绝；恢复前核对数量与版本，失败时不删本机资料。
- 需要迁入游客词库时，在**目标账号本机词库为空且电脑备份为空**的条件下进入账号页确认复制。复制后游客资料仍在，账号资料需再手动备份；若目标已有资料应拒绝复制。
- 管理员改密后所有旧会话失效，重新登录恢复电脑功能；退出应切回游客且账号词库保留。电脑关闭时尝试退出会提示连接失败并保留当前本机资料，避免把未撤销的服务会话误当作已退出。
